## Publication and confidentiality checklist

- [ ] Manufacturer-specific claims have a source.
- [ ] The exact model/variant is clear.
- [ ] Illustrative data are labelled as illustrative.
- [ ] No passwords, tokens, API keys, customer names, serial numbers, private network details, or proprietary documents are included.
- [ ] No unverified field tests, certifications, or performance claims are stated.
- [ ] Links and units have been checked.
